# SkyPulse 🌤️

A polished, responsive weather dashboard built with HTML, CSS and vanilla JavaScript.

## Features
- Current temperature and feels-like temperature
- Humidity, wind, cloud cover and precipitation
- Rain probability
- Sunrise and sunset
- 7-day forecast
- Next 12 hours temperature visualization
- City search with geocoding
- Browser geolocation
- Saved locations with localStorage
- Weather-aware UI
- Smart weather insights
- Automatic refresh every 10 minutes
- Responsive mobile and desktop design
- No API key required for normal non-commercial Open-Meteo usage

## Run
Open `index.html` in a modern browser. For browser geolocation, a local web server is recommended.

## Data
Powered by Open-Meteo Forecast API and Geocoding API.

The dashboard displays the latest available API/model data. Auto-refresh checks for newer data every 10 minutes; it is not a second-by-second thermometer.
